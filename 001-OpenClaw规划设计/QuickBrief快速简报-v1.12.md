# OpenClaw 快速简报｜v1.12

本版完整继承 v1.11，当前新增权威结论如下：

- 晨间玉简唯一正式样式为 2026-08-04 11:54 定稿，不得退回 11:55 扁平列表。
- 唯一正式触发是每天 06:00、`Asia/Shanghai` 的 command Cron；蕭觀音通过专用状态面查询，不从通用提醒数量猜测。
- 蕭觀音拥有所有可维护晨报输入的 typed Tool；賈南風只有持久转交入口，不能直接写 life 文件。只有 `applied` 才能向少主说已录入。
- 自动事实与人工偏好分层；日程事件和提醒时刻分存，默认提前 60 分钟。
- 正式多步任务使用 Skill 指引、Plugin 硬门和官方 Task Flow 状态；角色记忆文件不是工作流保证。
- 低风险自动，中风险内部完整复核并可回滚，只有高风险由角色自然询问一次；用户通道不出现原生工业审批卡。
- 当前 OpenClaw 版本没有 Task/Flow mutation Hook，旧 Workboard 分钟轮询在替代链可验收前继续保留。

实施和限制以 `002-OpenClaw部署进度/MorningBriefAndWorkflowRepair修复与生产验收报告-v0.01.md` 为准。
